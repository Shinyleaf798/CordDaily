# 项目规格文档

这份文档说的是「这个 App 应该长什么样、数据怎么存、接口有哪些」。
**改需求或加功能，先改这份文档，再动代码。**

数据表的精确定义（字段类型、默认值、关系）在 `backend/prisma/schema.prisma`，
那份文件才是准的。这里只用大白话说每张表存什么、为什么这么存。

## 1. 要做的功能

| 模块 | 功能 |
|---|---|
| 认证 | 注册、登录、登出 |
| 记账 | 新增 / 编辑 / 复制 / 删除一笔账（主题、备注、金额、币种、汇率、分类、账户、日期时间、标签、图片） |
| 分类 | 两级分类（父 + 子），增删改；图标可以是表情或内置图片；被账单用着的分类不许删 |
| 账户 | 多个账户各自的余额（现金 / 银行卡 / 电子钱包 / 信用卡 / 其他），账户之间转账 |
| 预算 | 一个月度总预算：填一个数，跟当月全部支出比；超了就提醒，在手机本地实时算 |
| 周期性交易 | 设一条规则（多久一次 / 多少钱 / 什么分类 / 哪个账户），App 打开时本地补生成 |
| 同步 | 数据存在手机本地，按周期（7天 / 1个月）自动同步或手动点「立即同步」，只往服务器推 |
| 统计（电脑端） | 月度收支趋势图、分类占比图、预算完成情况，全部只读 |

## 2. 数据表

一共 8 张表。

| 表 | 存什么 |
|---|---|
| 用户 | 邮箱、加密后的密码、本位币（默认 MYR） |
| 分类 | 名字、图标、收/支、属于谁；有一个「父分类」字段，为空就是一级分类 |
| 账户 | 名字、币种、期初余额。**没有「当前余额」这个字段** |
| 交易 | 一笔账的全部信息，见下面详细说明 |
| 交易图片 | 一个图片网址，挂在某笔交易下面 |
| 周期规则 | 多久一次、下次该生成的日期、开始和结束日期、是否启用 |
| 转账 | 从哪个账户、到哪个账户、多少钱、哪天 |

### 交易表里几个需要解释的字段

| 字段 | 干什么用 |
|---|---|
| 主题 | 列表主行显示的那句话。用户可以不填，不填就自动用「店名」或「分类名」顶上，保证永远不为空 |
| 店名 / 地点 | 会被反复输入的值（麦当劳、吉隆坡机场），所以做历史补全 |
| 备注 | 这一笔特有的明细（「3个汉堡2个薯条」），每笔都不一样，不做补全 |
| 汇率 / 折算后金额 | 记账时就把折算结果算好存下来 |
| 标签 | 跟分类平行的另一个汇总角度。一趟旅行横跨机票、餐饮、购物，只有标签圈得起来 |
| 可报销 + 收回时间 | 两个字段是两个状态：收回时间为空 = 还没收回，有值 = 已经收回 |
| 不计入统计 | 钱动了但不算「我的消费」（帮人垫付、一次性大额）。**注意账户余额不看这个字段**，余额必须真实 |

### 关键取舍

- **折算后的金额在记账时就算好**：汇率是用户当时自己查了填的，跟这笔账绑死，不是事后能用「今天的汇率」重算的东西。顺带也省了每次统计都要换算
- **id 由手机端生成**：手机离线创建的那一刻 id 就定了，同步时靠它判断「这笔是不是已经推过了」，网络重试不会存成两份
- **分类图标是一个带前缀的字符串，不拆成两列**：三种写法共用一个字段——表情（`🍜`）、内置图片（`builtin:food`）、用户自己的图片（`file://...`）。没有任何查询要按图标类型过滤，拆成两列只会让每张表、每次同步都多一个字段。内置图片存的是**引用**不是文件名，所以换图、改文件名都不用动数据库
- **预算只有一个总数，不按分类设**：口径是「本月全部支出（跳过『不计入统计』的）vs 那个数」。按分类设过一版，颗粒度太细、录入成本高于它带来的信息量，整个删掉了
- **预算存在手机本地的设置表里，不进服务器**：它是一个偏好值不是账目数据。代价是**换手机或重装会丢**，等做「设置同步」时一起解决
- **账户余额不存，每次现算**：余额 = 期初余额 + 收支和转账的汇总。存一个字段的话，离线同步迟早让它跟流水对不上
- **资产页不做汇总**：没有净资产、总资产/总负债、小计。账户在这个 App 里只有一个职责——让一笔账能记下「我用什么付的」。汇总数字要么首页已经回答过（本月花了多少），要么得靠用户认真维护每个账户的期初余额才成立（净资产），而维护那个正是这套东西最劝退的部分
- **账户没有分类，也没有类型**：账户存在的唯一目的是给一笔账贴上「我用什么付的」（现金、TNG、某张卡）。再给这些标签分一次类，在只有两三个账户时是纯仪式感。表上的 `type` 列留着恒为 `OTHER`——删它要整表重建，留一个没人读的列不碍事
- **周期规则和转账都是独立的表**：规则是「规则」，它生成的每一笔仍然是正常的交易；转账不计入收支统计，所以不混进交易表
- **图片只存网址**：图片本身直传图床，后端和数据库都不碰二进制
- **交易表留了一个「最后修改时间」**：现在电脑端只读用不上，但先加着，以后做网页编辑时可以用「谁改得晚听谁的」来处理冲突
- **只在两处加级联删除**：删用户时自动清掉他名下所有数据（为以后的注销账号准备）；删交易时自动清掉它的图片。其余关系一律是「还有账单在用就不许删」，避免「删个分类，几十笔账跟着消失」

## 3. 登录怎么做

- 注册时密码加密存，数据库里没有明文
- 登录返回两个凭证：一个 15 分钟过期的（每次请求带它），一个 7~30 天的（用来换新的那个）
- 短的过期了自动用长的换一个新的，用户不用重新登录
- 手机端把凭证存在系统的安全存储里

## 4. 接口清单

| 方法 | 路径 | 作用 |
|---|---|---|
| POST | `/auth/register` | 注册 |
| POST | `/auth/login` | 登录，返回两个凭证 |
| POST | `/auth/refresh` | 换一个新的短期凭证 |
| GET | `/auth/me` | 当前登录的是谁 |
| GET/POST | `/categories` | 分类：查 / 新建 |
| PUT/DELETE | `/categories/:id` | 分类：改 / 删 |
| GET/POST | `/accounts` | 账户：查 / 新建 |
| PUT/DELETE | `/accounts/:id` | 账户：改 / 删 |
| GET | `/accounts/:id/balance` | 算这个账户现在有多少钱 |
| GET | `/transactions?from=&to=&categoryId=&accountId=&type=` | 查账单，可按时间/分类/账户/收支筛 |
| POST | `/transactions/batch` | 同步用：一次推一批本地还没同步的账 |
| PUT/DELETE | `/transactions/:id` | 改 / 删一笔 |
| GET/POST | `/recurring-transactions` | 周期规则：查 / 新建 |
| PUT/DELETE | `/recurring-transactions/:id` | 周期规则：改（含暂停）/ 删 |
| POST | `/transfers/batch` | 同步用：一次推一批转账 |
| GET | `/transfers` | 查转账 |
| GET | `/stats/summary?month=` | 月度收支总览（电脑端画图用） |
| GET | `/stats/by-category?month=` | 按分类汇总（画饼图用） |

图片不走自己的后端——手机直接传到图床，拿到网址后跟着那批交易一起推上去。

## 5. 同步怎么做

- **什么时候同步**：App 打开时看「上次同步是什么时候」，超过设定的周期就自动同步；也可以随时手动点「立即上传」。两者走的是同一个函数
- **同步什么**：把本地所有「还没同步过」的交易、周期规则、账户、转账，单向推给服务器。预算不在其中
- **只存在手机本地、不上传的东西**：同步周期、上次同步时间、月度总预算。都放在本地的一张「设置表」里

**周期交易怎么补生成**（App 打开时跑）：

```
对每条启用中的规则：
  只要「下次该生成的日期」已经到了、而且没超过结束日期：
      本地创建一笔账（标记成还没同步，日期用那个日期）
      把「下次该生成的日期」往后推一个周期
  存回新的日期
```

这样长期不打开 App，再打开时会把欠的账一次补齐。

## 6. 页面结构

### 手机端

底部 5 个按钮：**首页 / 日历 / ＋添加（中间凸起的圆）/ 资产 / 我的**

| 页面 | 内容 |
|---|---|
| 首页 | 两套可切换布局（节奏条 / 金环）；本月收支总览；预算进度、已花多少、还剩多少、日均消费；没设预算时给一个入口直接填；近 7 天账单，点任意一笔弹出详情（编辑 / 复制 / 删除） |
| 日历 | 按天看账 |
| 添加账单 | 收支切换；分类网格（最后一格通到分类管理）；主题、备注、店名、地点；日期时间和账户；金额键盘；底部一行（报销 / 标签 / 不计入统计 / 拍照）。带上 id 就是编辑模式，同一个页面 |
| 资产 | 平铺的账户列表，每行显示余额。**不分组、不汇总**（见上面的取舍）。点一行进编辑页 |
| 新建/编辑账户 | 名称 + 期初余额（币种只读）。带上 id 就是编辑模式，同一个页面 |
| 我的 → 分类管理 | 按收支分组列出分类，增删改。跟记账页最后那格是同一页 |
| 我的 → 预算 | 填本月总预算 |
| 我的 → 周期交易 | 增 / 暂停 / 删规则 |
| 我的 → 同步设置 | 选同步周期、立即同步、显示上次同步时间和待同步笔数 |

### 电脑端（网页，只读）

| 页面 | 内容 |
|---|---|
| 登录页 | 邮箱密码登录 |
| 总览 | 月度收支趋势图、分类占比饼图 |
| 账单列表 | 按月/分类筛选看明细，不能编辑 |
| 预算总览 | 预算完成情况 |
| 设置 | 账号信息、登出 |

## 7. 部署（不租服务器）

| 层 | 用什么 |
|---|---|
| 数据库 | Neon（免费） |
| 后端 | Render 免费版（闲置会休眠，第一次请求要等 20~30 秒） |
| 网页 | Vercel 免费版 |
| 手机 App 打包 | Expo EAS（免费额度有限） |
| 图片 | Cloudinary 免费额度 |

不需要任何定时任务服务，因为周期交易改成手机本地生成了。
